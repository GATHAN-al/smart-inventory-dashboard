# 📦 Smart Inventory & Analytics Dashboard

Aplikasi Fullstack untuk manajemen inventaris barang yang dilengkapi dengan dashboard analitik real-time. Dibangun untuk mempermudah monitoring stok, nilai aset, dan kategori produk.

## 🚀 Tech Stack
- **Backend:** Laravel 11 (PHP)
- **Frontend:** React.js + Vite
- **Database:** PostgreSQL
- **Styling:** Tailwind CSS
- **Authentication:** Laravel Sanctum (API Token)
- **Visualization:** Chart.js

## 🔥 Fitur Utama
1.  **Dashboard Interaktif:** Grafik statistik stok per kategori dan ringkasan total aset.
2.  **Manajemen Produk (CRUD):**
    - Create: Tambah produk baru dengan validasi.
    - Read: Lihat daftar produk dengan format harga Rupiah.
    - Update: Edit detail produk (Stok, Harga, Nama).
    - Delete: Hapus produk dengan konfirmasi keamanan.
3.  **Autentikasi Aman:** Sistem Login user menggunakan token.
4.  **Responsive Design:** Tampilan rapi di desktop maupun mobile.

## 📂 Struktur Project
Project ini terdiri dari dua bagian utama:
- `/inventory` : Backend Code (Laravel)
- `/inventory-frontend` : Frontend Code (React)
